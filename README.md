# Abigail Endris · Portfolio

Live at **[endrisabigail.github.io/abbie](https://endrisabigail.github.io/abbie)**

My personal portfolio, built around a 3D sculpt of me that waves hello. I'm a computer science student at the University of North Texas, graduating December 2026, with a focus on full-stack development, UI/UX, 3D, and network security.

## What's inside

- **Projects:** Koda (UNT capstone), Hearth, and a PA-415 firewall lab from my Palo Alto Networks internship
- **Process:** write-ups on how I designed, sculpted, and built my projects, with wireframes, screenshots, and Nomad recordings
- **3D characters** sculpted in Nomad and Blender, viewable in the browser

## Built with

- React + Vite
- React Three Fiber / Three.js
- Nomad Sculpt and Blender for all 3D models (compressed with gltf-transform + meshopt)
- GitHub Actions for deployment to GitHub Pages
